# CitaSmart Barber - Plantilla Web & Sistema de Citas Premium

Plantilla web de alta barbería y sistema de reserva guiada en directo con diseño **Frosted Glassmorphism**, estética de lujo en tonos obsidiana y oro champagne, catálogo de productos de grooming y confirmación instantánea por WhatsApp.

---

## 🚀 Publicación Rápida a GitHub Pages (1 Solo Archivo HTML)

El proyecto incluye el archivo **`standalone-citasmart-barber.html`**, que contiene **todo el código (HTML5, CSS3, JavaScript puro y el logotipo vectorial de CitaSmart)** en **un único archivo autónomo**, sin dependencias ni necesidad de compilar con Node.js.

### Pasos para publicar en GitHub Pages:

1. **Crear o abrir tu repositorio en GitHub**:
   - Crea un nuevo repositorio (por ejemplo, `citasmart-barber`).
2. **Subir el archivo**:
   - Sube o renombra el archivo `standalone-citasmart-barber.html` como `index.html` en la rama principal (`main`).
3. **Activar GitHub Pages**:
   - En GitHub, dirígete a: **Settings** > **Pages**.
   - En **Build and deployment** > **Source**, elige **Deploy from a branch**.
   - Selecciona la rama `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**.
4. ¡Listo! En unos 30 segundos tu sitio estará en línea de forma gratuita en:
   `https://tu-usuario.github.io/tu-repositorio/`
